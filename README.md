Fáza 2 vrcholí. Posledná šifra.

## Čo ťa čaká

Swiss-K — najmenej známy stroj. Dva texty, len jeden je pravý.

**CESTA A** — prvý text:

`fgbrh twffo frppsuao aaglfe uiczwkkjvgurl.`

**CESTA B** — druhý text:

`jqams dwjyr bkqod, ewv oj rrjmcrssx.`

Nastavenia (cryptii.com → Enigma machine, DECODE):
Model Swiss-K, Reflector UKW, Position 2 (B), Ring 1 (A),
Rotor 1: I, Position 2 (B), Ring 25 (Y),
Rotor 2: II, Position 17 (Q), Ring 2 (B),
Rotor 3: I, Position 8 (H), Ring 1 (A),
Foreign chars: Include.

Odpoveď je POSLEDNÉ slovo dekódovaného textu.
